

# Welcome to Shroom Raiders!
- Laro, the player, needs your help in collecting all the mushrooms scattered everywhere!
- Collect all the mushrooms to win the game.
- Be careful not to fall into the water; he'll die and lose the quest!
- Push rocks to pave new paths!
- Pick up miscellaneous items to clear obstacles!

# Bonus features:
- Leaderboards! (Finish levels in as few moves as possible to get higher scores.)
- *Animations! (...that can be done in a terminal.)
- Alternate control schemes.
- Crates, walls, and hammers.

# Controls:
- Select a WASD or ULDR control scheme of your choice.
- Select P to pick up items you're on top of.
- Type "!" to reset and "q" to quit the level.
- (Inputs can be both uppercase and lowercase!)

Controls apply once [Enter] is pressed. 
You can type a string of moves, then press [Enter] to execute them in one go.

# Items
- Axe: walk into a tree to cut it down. Clears the tree's tile.
- Flamethrower: walk into a tree to burn it and start a forest fire. Burning trees will spread to nearby trees, clearing many in one go.
- *Hammer: walk into walls and rocks to break them. Clears a wall or rock's tile. (You can't push rocks while holding a hammer until you use it up...)
